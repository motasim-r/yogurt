# Yogurt Desktop App

Electron + React desktop app for the unified Yogurt monorepo.

This app is now the canonical UI/control center for:

1. Granola context auth, sync, and local persistence
2. Home, chat, docs, and tasks inside one desktop product shell
3. Task execution, planning, and realtime run updates

Product doctrine:

- [`../../docs/yogurt-soul.md`](../../docs/yogurt-soul.md)

## Local commands (from this folder)

- `npm run dev`
- `npm run build`
- `npm run start`
- `npm run test`
- `npm run typecheck`
